# 飞瀑能源管理系统 · 用户手册

> 版本 v1.0.0 · 适用角色：全部 7 角色 · 演示口令统一 `energy@2026`

## 一、系统定位

面向制造企业的能源管理（Energy Management System, EnMS），覆盖 GB/T 23331 / ISO 50001 核心业务：
计量抄表 → 能耗统计 → 单耗对标 → 设备能效 → 节能项目 → 碳排核算 → 预算管控。

## 二、登录

浏览器打开系统地址（如 `http://<服务器>:8021/pu/`），输入账号口令。

| 账号 | 姓名 | 角色 | 主要权限 |
|---|---|---|---|
| admin | 系统管理员 | 系统管理员 | 全部 |
| manager | 能源主管·李工 | 能源主管 | 业务全权 + 验证 + 规则 |
| staff | 能源专员·王敏 | 能源专员 | 归集分析、抄表管理 |
| reader | 抄表员·赵强 | 抄表员 | 抄表录入与质检 |
| engineer | 设备工程师·陈涛 | 设备工程师 | 设备能效、节能项目 |
| prod | 生产经理·刘阳 | 生产经理 | 只读业务数据 |
| finance | 财务·周琳 | 财务 | 只读预算与报表 |

首次登录后请在右上角「修改口令」中改密（≥6 位）。改密后原令牌全部失效。

## 三、页面速览

### 1. 仪表盘
- 8 张 KPI 卡：综合能耗(tce)、碳排放、单位产品能耗、单位产值能耗、最大需量、本期电量、待处置告警、预算执行率
- 近 6 期综合能耗趋势 + 能源介质结构环形图 + 成本中心排名条形图
- 单耗偏离基线 8% 以上的产线自动列出（正常/警告/严重/紧急四级）

### 2. 抄表与采集（reader / staff / manager）
- 「手工抄表」：选计量点、期间、表底，系统自动算用量 =（本期表底−上期表底）×倍率
- 「批量抄表」：一次录入多点，部分失败不影响成功项
- 「网关上报模拟」：采集网关按 `ts` 自动推导期间
- **三条硬校验**：
  - 表底倒走 → 拒绝（409）
  - 同点同期重复 → 拒绝（409 区间重叠）
  - 环比 3 倍且绝对量 >100 → 允许入库但标记「跳变」并自动告警

### 3. 分时与需量
- 四时段（尖峰 1.28 / 峰 1.02 / 平 0.68 / 谷 0.34 元/kWh）电费与占比
- 24 小时需量曲线，超容量 85% 预警 / 95% 紧急 / 100% 超容自动告警
- 容量电费 = 最大需量 × 42 元/kW·月

### 4. 能耗分析 / 单耗与基线
- 按「中心 × 介质」聚合，支持筛选导出 CSV
- 单耗 = 综合能耗 ÷ 产量（6 位精度），对比锁定基线自动分级

### 5. 设备能效（engineer）
- 四类指标：空压机比功率（≤6.3 优）、水泵效率（≥75% 优）、锅炉热效率（≥92% 优）、制冷机 COP（≥5.0 优）
- 内置计算器：输入实测参数即时出评级
- 录入测试后自动与上次对比，劣化超 5% 自动告警

### 6. 节能项目（engineer / manager）
- 立项须绑定基线；验证三闸口：无基线 / 无计量数据 / 产量为 0 均拒绝
- 节能量 =（基线单耗 − 报告期单耗）× 产量；年节费按 620 元/tce 年化；自动算回收期

### 7. 告警中心
- 五级看板 + 三维筛选（级别/状态/类型）+ 处置留痕
- 同一告警不可重复处置（409）

### 8. 能源预算
- 按「中心 × 介质 × 期间」限额
- 90% 预警 / 100% 超支 / 110% 阻断（blocked 标记）

### 9. 碳排放
- 范围一（天然气/柴油直接排放）+ 范围二（电力/蒸汽/水/压缩空气间接排放）
- 碳强度 = 碳排 ÷ 产值(万元)，支持 CSV 导出

### 10. 报表中心
- 能源平衡表（输入=使用+损耗，校验差恒 0）、日报、碳排
- 四类 CSV 导出（带 UTF-8 BOM，Excel 直接打开）

### 11. 系统管理（admin / manager 分 tab 可见）
- 用户管理：7 角色矩阵，停用即时拒登
- 业务规则：14 项阈值（需量预警比、跳变比、预算闸口、标煤价等）改后即时生效
- 接口密钥：`fpk_` 开头长期密钥，明文仅显示一次，可绑定角色
- Webhook：订阅 13 种事件，HMAC-SHA256 签名推送
- 审计日志：登录、写操作、处置全留痕

## 四、常见问题

**Q：抄表时提示「区间重叠」？**
同计量点同期间只能有一条记录。若录错需联系管理员在数据库更正（系统不提供删除，保证审计连续）。

**Q：改了业务规则没生效？**
规则即时生效于新请求。历史数据按入库时口径计算，不会回刷。

**Q：看板数字与我的口径不一致？**
看板折标煤用介质表 `tce_factor`，可在「能源介质」中核对该介质系数（电力 0.0001229 tce/kWh 为当量值口径）。

**Q：如何与 MES/ERP 对接？**
方式一：`POST /api/readings/report` 由采集网关推送；
方式二：`GET /api/sync/changes` 增量拉取；
方式三：Webhook 订阅事件推送。
详见《API 接口文档》(docs/api.md) 与线上 `/apidoc`。
